Slack + Claude Code: read-only digest and drafts

Connect Slack to Claude Code as read-only, then add two skills. One writes a daily digest of your messages. The other drafts replies in your voice and puts them on your clipboard. It never sends anything. You do.

  1. Download all three files.
  2. Follow SETUP.md to connect Slack and lock it to read-only.
  3. Install the skills, or tell Claude Code: Install these two skills from my Downloads folder.
  4. Run /slack-digest or /slack-draft <what you want to say>.
